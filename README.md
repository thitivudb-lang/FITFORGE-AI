FITFORGE — AI Workout Planner

เว็บแอปวางแผนออกกำลังกายส่วนบุคคล คำนวณ BMI เลือกท่าตามเป้าหมาย ระดับ อุปกรณ์ที่มี และข้อจำกัดทางร่างกาย พร้อมโหมดออกกำลังกายแบบมีไกด์ ตัวจับเวลา และระบบติดตามความก้าวหน้า

ทำงานฝั่งเบราว์เซอร์ทั้งหมด ไม่มี backend และข้อมูลทั้งหมดเก็บในเครื่องของผู้ใช้เท่านั้น

Demo: https://thitivudb-lang.github.io/FITFORGE-AI/

เทคโนโลยีที่ใช้
ภาษา / เทคโนโลยี	ใช้ทำอะไร
HTML5	โครงหน้าเว็บ (index.html)
CSS3	สไตล์ทั้งหมดใน Styles.css ใช้ CSS Variables, Grid, Flexbox, Media Queries และ @media print
JavaScript (ES6+)	ตรรกะทั้งหมดใน App.js
React 18	สร้าง UI แบบ component ใช้ Hooks (useState, useEffect, useMemo, useCallback)
JSX + Babel Standalone	เขียน JSX แล้วแปลงในเบราว์เซอร์ ไม่ต้อง build
localStorage	เก็บโปรไฟล์ โปรแกรม และประวัติการฝึกในเบราว์เซอร์
Google Fonts	Bebas Neue, Manrope, IBM Plex Mono

React, ReactDOM และ Babel โหลดผ่าน CDN (cdnjs) ส่วนไอคอนและกราฟเขียนเองด้วย SVG จึงไม่ต้องพึ่งไลบรารีเพิ่ม

ฟีเจอร์
Profile และ BMI — คำนวณ BMI ตามเกณฑ์ WHO Asia-Pacific (18.5 / 23 / 25 / 30) แสดงเป็นเกจวงกลม
Workout Setup — เลือกเป้าหมาย (ลดน้ำหนัก, เพิ่มกล้ามเนื้อ, เพิ่มความแข็งแรง, สุขภาพทั่วไป) ระดับประสบการณ์ ส่วนของร่างกาย อุปกรณ์ จำนวนวันต่อสัปดาห์ และเวลาต่อครั้ง
สร้างโปรแกรมอัตโนมัติ — แบ่งตารางฝึกรายสัปดาห์ (Full Body / Upper-Lower / Push-Pull-Legs ตามจำนวนวัน) แล้วเลือกท่าจากฐานข้อมูล
ฐานข้อมูลท่าออกกำลังกาย — 40+ ท่า มีวิธีทำทีละขั้นตอน ข้อควรระวัง และลิงก์แหล่งอ้างอิง
กรองตามข้อจำกัดร่างกาย — ถ้าระบุว่ามีอาการบาดเจ็บ ระบบจะตัดท่าเสี่ยงสูงออก
สลับท่า — เลือกท่าทดแทนที่ใช้อุปกรณ์เดียวกันและรูปแบบการเคลื่อนไหวใกล้เคียง
โหมดออกกำลังกายแบบมีไกด์ — วอร์มอัพ → ทำทีละเซตพร้อมตัวจับเวลาพัก → บันทึกน้ำหนักที่ใช้ → คูลดาวน์
ปุ่ม "ท่านี้ทำให้เจ็บ" — สลับท่าหรือลดจำนวนครั้งลงครึ่งหนึ่งทันที และจำท่านั้นไว้ไม่ให้แนะนำซ้ำ
Progressive Overload — ฝึกต่อเนื่องทุก 2 สัปดาห์ ระบบเพิ่มเป้าหมายจำนวนครั้งขึ้นเล็กน้อย
Streak และ Achievement — นับสัปดาห์ที่ทำได้ถึง 75% ของเป้าหมาย และปลดล็อกความสำเร็จ 7 ระดับ
กราฟความก้าวหน้า — น้ำหนักตัว และน้ำหนักที่ยกได้ต่อท่า
พิมพ์ / บันทึกเป็น PDF — มีสไตล์สำหรับพิมพ์โดยเฉพาะ (ธีมสว่าง ทุกวันในรายการเดียว)
Responsive — มี Sidebar บนเดสก์ท็อป และ Bottom Navigation บนมือถือ
วิธีทำงานของการเลือกท่า

การเลือกท่าและตัวเลขเซต/ครั้ง/พัก คำนวณด้วยอัลกอริทึมแบบ deterministic ไม่ได้สุ่มและไม่ได้ให้ AI สร้างเอง

กรอง ท่าจากฐานข้อมูลตามส่วนของร่างกาย ระดับความยาก อุปกรณ์ที่มี ข้อจำกัดร่างกาย และท่าที่เคยทำให้เจ็บ
แบ่งวัน ตามจำนวนวันต่อสัปดาห์
เลือกท่า ต่อวัน ตามเวลาที่มี (ประมาณ 1 ท่าต่อ 8 นาที สูงสุด 8 ท่า)
กำหนดเซต/ครั้ง/พัก จากตารางเป้าหมาย × ระดับ ซึ่งอ้างอิงแนวทางของ NASM, Mayo Clinic, NHS และ ACSM

ในเวอร์ชันนี้สร้างจากเทมเพลตในเครื่อง ไม่ได้เรียก AI ภายนอก เพราะหน้าเว็บ static ไม่มี backend และไม่ควรเก็บ API key ไว้ฝั่งผู้ใช้

ชื่อไฟล์ต้องตรงกับที่เรียกใน index.html ทุกตัวอักษร (รวมตัวพิมพ์เล็ก/ใหญ่) เพราะ GitHub Pages แยกตัวพิมพ์

วิธีรันบนเครื่อง

ต้องเปิดผ่านเซิร์ฟเวอร์ ดับเบิลคลิก index.html ตรง ๆ จะไม่ทำงาน เพราะ Babel โหลด App.js ด้วย XHR ซึ่งเบราว์เซอร์บล็อกเมื่อเปิดแบบ file://

bash
python3 -m http.server 8000
# เปิด http://localhost:8000

หรือใช้ส่วนเสริม Live Server ใน VS Code

ข้อมูลทั้งหมด (โปรไฟล์ โปรแกรม ประวัติการฝึก น้ำหนัก) เก็บใน localStorage ของเบราว์เซอร์ โดยใช้คีย์ขึ้นต้นว่า fitforge: ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ใด ๆ
